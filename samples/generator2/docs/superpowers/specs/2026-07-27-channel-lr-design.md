# Каналы CHL/CHR: правильное лево/право, единые цвета

Дата: 2026-07-27
Статус: утверждён

## Проблема

Пользователи не понимают «канал 1 / канал 2» — понятнее «левый / правый».
Хуже того: подписи врут. Приложение внутренне консистентно считает
ch1 = «L» (жёлтый), ch2 = «R» (магента), но финальный интерлив в
`AudioMixerPump` собран как `bufMerge(outR, outL)` — outR попадает в чётные
позиции LRLR-потока, а чётный сэмпл AudioTrack играет в **левом** ухе.
Итог: ch1 звучит справа, ch2 слева. MP3-путь перевёрнут так же.

## Цель

1. Чётный сэмпл интерлива = левое ухо (конвенция AudioTrack LRLR),
   и канал, подписанный «левый», реально играет слева.
2. Уйти от «1/2» к «CHL/CHR» во всём UI и коде.
3. Единые цвета идентичности канала: **CHL = жёлтый #FFFF00**
   (`vec3(1.0, 1.0, 0.0)`), **CHR = магента #FF00FF** (`vec3(1.0, 0.0, 1.0)`) —
   как у трасс осциллографа.

## Решения (утверждены)

- ch1 → CHL (верхняя карточка = левый), аудио чиним, не подписи.
- Полный ренейм в коде; строковые ключи файлов пресетов **не меняются**.
- Скрипт-язык: `CHL`/`CHR` + легаси-алиасы `CH1`/`CH2`.
- Цвета применяются везде, где есть идентичность канала.
- Дефолты роутов: оба `GEN` (сейчас `routeL = OFF` — звук в одном ухе).
- Подход: точечный фикс, без рефакторинга аудиотракта.

## Секция 1. Аудиотракт

Файл `features/audio/AudioMixerPump.kt`:

- Нормальный режим: `bufMerge(outL, outR)` — outL в чётные позиции (лево).
  Shuffle: `bufMerge(outR, outL)`.
- Дефолты: `routeL = MutableStateFlow(ROUTESTREAM.GEN)`, `routeR = GEN`.
- `routeL`, `invertL`, `Mp3Route("L")` после фикса физически совпадают со
  своими именами — не трогаем.
- MP3: `split()` уже кладёт чётный сэмпл в left — после фикса настоящий
  левый канал MP3 играет слева. Отдельных правок не требует.

## Секция 2. Визуальные потребители интерлива

Все читают тот же буфер `v`. Новая семантика: чётный = L. Картинка
осциллографа визуально не меняется (жёлтый сверху, магента снизу) —
меняется только соответствие ушам.

- `MyGLRendererOscill` фрагментный шейдер: grid-канал 0 (чётный, L) →
  жёлтый `vec3(1.0, 1.0, 0.0)`, канал 1 (R) → магента `vec3(1.0, 0.0, 1.0)`
  (сейчас наоборот).
- `cpp/scope/PhosphorGrid.h` `binOf()`: канал 0 (L) — верхняя половина,
  канал 1 — нижняя (свап текущих формул `±0.5`).
- Wiring visibility в `Scope.kt`/`MyGLRendererOscill`: `visibility.x ←
  isVisibleL`, `visibility.y ← isVisibleR` (сейчас перекрёстно).
- Лиссажу (`MyGLRendererLissagu`): проверить маппинг канал → ось X/Y,
  сохранить текущую картинку с правильными подписями.
- Спектрограмма (`cpp/spectrogram/jniFFT.cpp`, pProcessorL/R) и старый
  `cpp/scope/canvas.cpp` (bufLN = чётный) считают чётный = L — после фикса
  станут правы автоматически. Проверить подписи L/R в waterfall UI.

## Секция 3. Ренейм кода (совместимость данных)

- `liveData.ch1_*` → `chL_*`, `ch2_*` → `chR_*` (включая `ch1AmDepth` →
  `chLAmDepth` и пр.); `gen.ch1`/`gen.ch2` → `gen.chL`/`gen.chR`.
- Enum `GeneratorCH.CH0/CH1` → `CHL/CHR`; строковые параметры карточек
  `"CH0"/"CH1"` заменить на enum — третий слой имён исчезает.
- **Пресеты**: ключи `ch1_*`/`ch2_*` в файлах остаются как есть — только на
  границе сериализации (`presetsSaveFile.kt`, `presetsReadFile.kt`,
  `presetsToLiveData.kt`) с комментарием «legacy-ключи, не переименовывать».
  Старые пресеты работают без миграции.
- **Скрипты**: парсер `ScriptCommand` принимает `CHL`/`CHR` и алиасы
  `CH1`(=CHL)/`CH2`(=CHR). `ScriptKeyboard` выдаёт только `CHL`/`CHR`.
  Старые сохранённые скрипты работают.
- **Ноды**: в JSON графа поле `ch: Int` (1/2) остаётся — старые графы
  читаются; пикер `ReadGenDialog` показывает `CHL`/`CHR`.
- Механические правки по месту: `observe.kt`, `Spinner_Send_Buffer.kt`,
  `RenderChannel.kt`, `mainscreen4.kt`, карточки, `SoundService`.

## Секция 4. Цвета и UI

- Тема: `colorChL = Color(0xFFFFFF00)`, `colorChR = Color(0xFFFF00FF)` —
  единственный источник в Kotlin. В шейдере те же значения с
  комментарием-ссылкой на константы темы.
- Карточки: полоса CHL зелёная → жёлтая, CHR оранжевая → магента; в полосу
  добавить текст-лейбл «CHL» / «CHR» (сейчас канал не подписан).
- Скрипт-клавиатура: кнопки CHL/CHR в своих цветах; рендер команд в
  `ScriptItem` — тоже.
- Ноды: пикер CHL/CHR с цветами. MP3-роут: кнопки «L»/«R» → жёлтый/магента.
- Scope UI: кнопки L/R уже жёлтая/магента — перевести на константы темы.

## Секция 5. Верификация

- Юнит: порядок bufMerge (первый аргумент → чётные индексы = L); алиасы
  парсера скриптов; roundtrip пресетов со старыми ключами.
- Руками на устройстве: тон только CHL → звук строго в левом наушнике,
  трасса жёлтая сверху; стерео-MP3 с разными каналами — уши совпадают с
  подписями; waterfall L/R.
- Сборка + существующие тесты проекта.

## Вне скоупа

- Рефакторинг аудиотракта (StereoRouter) — отклонён, точечный фикс.
- Миграция ключей пресетов и формата графов — не нужна.
- Изменение семантики shuffle/invert — сохраняются как есть.
